# Sokher Alankar website assets

Logo, icons, share image, pattern and font files for the Sokher Alankar website, served through jsDelivr:
`https://cdn.jsdelivr.net/gh/NDcompany/sokher-alankar-assets@v1/<path>`

The theme links to a tagged version (`@v1`), so a changed file needs a new tag and a theme update.
The fonts are subsets of Cormorant Garamond, Hind Siliguri and Tiro Bangla under the SIL Open Font License (`fonts/OFL-*.txt`).
